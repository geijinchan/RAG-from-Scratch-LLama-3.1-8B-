DIAGRAM 4: DATA FLOW - TRANSFORMATIONS AT EACH STAGE
═══════════════════════════════════════════════════════════════════════════════

├─ STAGE 0: INPUT
│  └─ Raw PDF file (50-100 MB)
│
├─ STAGE 1: PDF EXTRACTION
│  Input:  Raw PDF file
│  Process: extract_text_from_pdf()
│  Output: List[{"page_number": int, "text": str}]
│  Example: [{"page_number": 0, "text": "Chapter 1: Introduction..."}]
│
├─ STAGE 2: SENTENCE SPLITTING
│  Input:  List[{"page_number", "text"}]
│  Process: split_into_sentences() [spaCy NLP]
│  Output: List[{"page_number", "sentences": []}]
│  Example: [{"page_number": 0, "sentences": ["Intro.", "This is..."]}]
│
├─ STAGE 3: SENTENCE CHUNKING
│  Input:  List[{"page_number", "sentences"}]
│  Process: chunk_sentences() [group by N sentences]
│  Output: List[{"page_number", "sentence_chunks": [[]]}]
│  Example: [{"page_number": 0, "sentence_chunks": [["Intro.", "This is..."], ...]}]
│
├─ STAGE 4: CHUNK CREATION
│  Input:  List[{"page_number", "sentence_chunks"}]
│  Process: create_chunks() [join, count tokens]
│  Output: List[{"page_number", "sentence_chunk", "token_count", "char_count"}]
│  Example: [{"page_number": 0, "sentence_chunk": "Intro. This is...", "token_count": 45}]
│
├─ STAGE 5: CHUNK FILTERING
│  Input:  List[{"page_number", "sentence_chunk", "token_count", ...}]
│  Process: filter_chunks() [remove short chunks]
│  Output: List[{"page_number", "sentence_chunk", "token_count", ...}]
│  Example: 234 chunks remain (from 240 original)
│
├─ STAGE 6: EMBEDDING GENERATION
│  Input:  List[{"page_number", "sentence_chunk", ...}]
│  Process: embed_chunks() [SentenceTransformer.encode()]
│  Output: List[{"page_number", "sentence_chunk", ..., "embedding": <1x768>}]
│  Example: {..., "embedding": [0.123, -0.456, ..., 0.234]}
│
├─ STAGE 7: RETRIEVER SETUP
│  Input:  List with embeddings
│  Process: SemanticRetriever.__init__() [convert to torch tensors]
│  Output: Retriever instance with torch embeddings tensor <234x768>
│
├─ STAGE 8A: QUERY EMBEDDING (for retrieval)
│  Input:  Query string: "What are macronutrients?"
│  Process: SentenceTransformer.encode(query)
│  Output: Query embedding <1x768>
│
├─ STAGE 8B: SIMILARITY SEARCH
│  Input:  Query embedding + Chunk embeddings
│  Process: torch.nn.functional.dot_score()
│  Output: Similarity scores <234,> (one score per chunk)
│
├─ STAGE 9: TOP-K RETRIEVAL
│  Input:  Similarity scores
│  Process: torch.topk(scores, k=5)
│  Output: Top 5 chunks with highest scores and their texts
│  Example: [
│    {"page": 12, "text": "Macronutrients...", "score": 0.91},
│    {"page": 15, "text": "There are three...", "score": 0.84},
│    ...
│  ]
│
├─ STAGE 10: PROMPT FORMATTING
│  Input:  Query + Top-k context chunks
│  Process: format_prompt_with_context() [combine with template]
│  Output: Formatted prompt string (~512 tokens)
│  Example: "<|begin_of_text|>...[context]...[query]Answer:"
│
├─ STAGE 11: TOKENIZATION
│  Input:  Formatted prompt string
│  Process: tokenizer(prompt) [convert to token IDs]
│  Output: Token ID array and attention mask
│  Example: [1, 882, 4678, 2991, ..., 3890]
│
├─ STAGE 12: GENERATION
│  Input:  Token IDs
│  Process: model.generate() [iterative token prediction]
│  Output: Extended token ID array with generated tokens
│  Example: [1, 882, ..., 3890, [new_token], [new_token], ...]
│
├─ STAGE 13: DECODING
│  Input:  Generated token IDs
│  Process: tokenizer.decode() [convert tokens back to text]
│  Output: Clean generated text string
│  Example: "Macronutrients are organic compounds..."
│
└─ STAGE 14: OUTPUT
   Final Answer: "Macronutrients are organic compounds..."
   + Context: [top 5 chunks with scores]
   + Visual display in Streamlit
